# Excel-Data-Analysis-and-Visualization
### Excel Data Cleaning & Interactive Dashboard

Cleaned and validated a customer sales dataset using Microsoft Excel, addressing inconsistent labels and capitalization, extra spaces, missing values, duplicate records, and invalid quantity and price entries. Documented data-quality issues and created calculated fields for valid quantities and revenue.

Used Excel Tables, formulas, PivotTables, PivotCharts, slicers, and a date timeline to build an interactive sales dashboard featuring KPI cards and revenue and product-demand analyses.

The dashboard enables users to explore sales performance by product, category, state, salesperson, payment status, and date, supporting comparisons of revenue, product demand, and sales trends while highlighting data-quality limitations that may affect analysis.
